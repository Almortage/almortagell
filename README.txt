# موقع محمد عبدالجواد «المرتجل»

## التشغيل
1. افتح الملف `index.html` في المتصفح.
2. الصور موجودة داخل مجلد `images`.
3. لا تحذف مجلد `images` أو تغيّر أسماء الملفات إلا إذا عدّلت المسارات في `index.html`.

## تخصيص بيانات التواصل
افتح `index.html` و`script.js` وابحث عن:
- `your@email.com`
- `data-placeholder-link`

ضع بريدك الحقيقي وروابط واتساب/إنستجرام/فيسبوك.

## ملاحظة نموذج التواصل
النموذج الحالي يستخدم `mailto:`؛ أي أنه يفتح تطبيق البريد لدى الزائر ويجهز الرسالة تلقائيًا.
لإرسال مباشر من الموقع بدون فتح تطبيق البريد، يلزم ربطه بخدمة إرسال/Backend.
